# Personal portfolio — João Lorenzo Rebaudo

Static portfolio for recruiters (CS internships).
Live at https://joaolorenzorebaudo-lab.github.io
Full spec: docs/spec.md — read it before proposing changes.

## Stack
- Plain HTML, CSS and a little vanilla JavaScript
- No frameworks, no build tools, no npm packages
- Local preview: python3 -m http.server, then open http://localhost:8000

## Out of scope (v1) — do not add or suggest
Contact form, blog, dark mode, complex animations, frameworks, custom domain, analytics.

## Code style
- Code, file names and comments in English
- Semantic HTML: header, nav, main, section, footer
- Comments only where the intent is not obvious
- No tool signatures or emojis in code and commit messages (how the code was written is explained in the README)
- Commit messages: "feat: …", "fix: …", "docs: …", "style: …"

## Working with me (I'm learning)
- This is my project: I make the decisions, you assist.
- Before editing files, show me the plan and wait for my OK.
- Show me the diff and wait for my OK before every commit.
- You write the HTML, CSS and JavaScript. I provide the page text at each step and review every change.
- I push from my own terminal. Never assume what is pushed: check git status first.
- Explain every non-obvious choice in 1–2 lines.
- One small step per commit.
