# P1 — Portfolio personale multilingue (spec v1.0)

Problema: un recruiter deve capire in 30 secondi chi sono, cosa e dove studio, e vedere i miei progetti.
Utente: recruiter che cerca stagisti in informatica, in Lussemburgo e in Italia.
Tipo: sito statico (solo front end), ospitato su GitHub Pages.

## Sezioni
1. Hero: nome, foto, "Studente di Informatica @ UniFi", città, bottoni "Scarica CV" e LinkedIn
2. Progetti: una card per progetto con i tag delle tecnologie (oggi: questo sito)
3. Percorso: formazione, esperienze, lingue
4. Contatti: email, LinkedIn, GitHub

## Lingue
- v1: EN (default), IT, FR
- v1.1: PT, ES

## Requisiti
- CV in PDF (inglese) scaricabile dalla Hero (rimandato: non è nella v1)
- Dati di contatto online: solo l'email (niente telefono né indirizzo)
- Aggiungere un progetto: < 10 minuti
- Aggiungere una lingua: < 30 minuti
- Elemento distintivo: nella Hero un saluto che cambia lingua (Ciao → Olá → Bonjour → Hello → Hola). Unica animazione ammessa.

## Fuori scope (v1)
Form contatti, blog, dark mode, animazioni complesse, framework, dominio personalizzato, statistiche visite, CV multilingue.

## Definition of done
- Online su GitHub Pages
- Test dei 30 secondi: 2 persone guardano il sito e sanno dire cosa studio e dove
- README
- Retro scritta
